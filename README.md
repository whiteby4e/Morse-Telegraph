# Morse Telegraph

A Morse telegraph system with UART communication, Serial Monitor output, and TFT display.

## Versions

This repository contains different versions of the project:

* **Serial Monitor** — Morse communication with Serial Monitor output.
* **TFT** — Morse communication with an ST7735 TFT display.
* **UART** — Basic UART communication and testing.

## Hardware

The project can be built and experimented with using different microcontrollers and hardware modules.

Current setup includes:

* Raspberry Pi Pico
* ESP32
* ST7735 TFT display
* Buzzer
* Push buttons
* UART communication

## Features

* Morse code input
* Morse code decoding
* UART communication
* Serial Monitor output
* TFT display interface
* Buzzer feedback

## Project Status

Experimental / learning project.

More features and hardware may be added in the future.
